# ZorgNed

Zoekbare werkinstructies voor ZorgNed.

**Website (na inschakelen van GitHub Pages):** https://mlemson.github.io/zorgned/

## GitHub Pages
Ga naar **Settings → Pages** en kies onder **Build and deployment**:
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Sla op. De website gebruikt `index.html` in de hoofdmap.

## Publicatie
Dit is een publieke, statische website zonder database of externe scripts. De oorspronkelijke interne PDF en schermafbeeldingen met identificeerbare gegevens zijn niet meegepubliceerd. Controleer vóór publiek gebruik of de inhoudelijke werkafspraken gedeeld mogen worden.

## Aanpassen
Bewerk `index.html` en commit naar `main`. GitHub Pages publiceert wijzigingen automatisch.
